# 渲染体检提示词（v0.0.84）

> 用途：把下面整段贴进**对话页**（任意题目或自由会话）发送，逐项检查回答是否正确渲染。
> 每个版本想回归渲染链路时用同一份，结果可比。

## 提示词（复制下面整段发送）

请严格按下面 18 项「渲染体检单」逐项输出，**每一项都要真的渲染出来**，不要合并、不要省略、不要解释你在做什么，直接按编号给结果。这份回答的唯一目的是把客户端的每一种渲染能力都压一遍。

**一、基础排版**

1. 一级、二级、三级标题各一个（内容自定，与数学辅导相关）。
2. 同一段里出现：**加粗**、*斜体*、`行内代码`、~~删除线~~、[一个链接](https://example.com)。
3. 有序列表、无序列表、两层嵌套列表各一个。
4. 一段 `>` 引用，引用内嵌一行普通说明文字。
5. 一个围栏代码块（语言标 kotlin，内容 3–5 行）。

**二、行内公式**

6. 一句话里连续混排 5 个行内公式：$x^2$、$\frac{a}{b}$、$\sqrt{2}$、$\alpha+\beta$、$x \leq y$。

**三、独立公式块**

7. 三行等号对齐推导，用 `$$\begin{aligned} ... \end{aligned}$$`。
8. 二阶矩阵：`$$\begin{pmatrix} a & b \\ c & d \end{pmatrix}$$`。
9. 带中文标注：`$$\vec{F} = m\vec{a} \quad \text{（牛顿第二定律）}$$`。
10. 结论框：`$$\boxed{x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}}$$`。
11. 求和与极限各一个：`$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$` 与 `$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$`。
12. 上下标综合：`$$a_n = a_1 q^{n-1}, \quad S_n = \frac{a_1(1-q^n)}{1-q}$$`。

**四、表格**

13. 一个 4 行 3 列 Markdown 表格（物理量 / 符号 / 单位），其中一行的符号列是行内公式。

**五、示意图**

14. 用 ```svg 围栏画一个直角三角形：标出直角小方块、斜边标注字母 h。

**六、版式化内容**

15. 用 ```html 围栏做一张左右两列对比卡片（左「匀速直线运动」右「自由落体」，各 3 行要点），其中各嵌一个行内公式（$v = at$、$h = \frac{1}{2}gt^2$）。

**七、压力项**

16. 一条故意很长的公式（分母套分母再套根号，超过一行宽度），观察是否完整显示。
17. 连续三句「中文 + 行内公式 + 中文标点」混排：如「当 $x > 0$ 时，$f(x)$ 单调递增。」×3。
18. 两个独立公式块背靠背输出，中间不夹任何正文。

## 验收清单（人工核对）

| 项 | 看什么 |
|---|---|
| 1–5 | 层级样式正确；链接点击走系统浏览器；代码块等宽字体、不执行 |
| 6 | 5 个行内公式全部渲染、基线不跳动、和中文之间留白正常 |
| 7 | 三行以 `&` 对齐；公式块内不出现红色源码 |
| 8–12 | 矩阵有圆括号；中文进 \text 不乱码；\boxed 有框；Σ/lim 上下限位置正确 |
| 13 | 表格边框完整，单元格内公式不溢出 |
| 14 | SVG 显示为图而非源码；直角符号可见 |
| 15 | HTML 卡片有样式、双列并排；块内公式被 KaTeX 渲染而非显示 `$...$` 源码 |
| 16 | 长公式整条可见（换行或等比缩放），右缘不被裁 |
| 17 | 公式与中文标点间距正常，无多余换行 |
| 18 | 两块公式独立成块，不粘连、不互相吞定界符 |
