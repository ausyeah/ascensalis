## v0.0.86

v0.0.86 - 背单词每日新词上限设置 UI 修复、成就墙重排版与排序

### 更新内容

**本版修复你反馈的两个问题：**

1. **背单词「每日新词上限」设置 UI 异常**
   - 旧版本里「0 = 不限」的历史数据会原样透传，而新档位（50 / 100 / 200 / 自定义）里没有任何一项能表达「不限」，于是设置页显示成「自定义（0）」、四个档位一个都不选中——实际行为与显示对不上。
   - 现在读取时会把历史脏值收敛进合法区间（1..500）：低于下限回落默认档 20，只有高于上限才收到 500，任何时候都有一个档位处于选中状态。
   - 设置页排版：标题独占一行（右侧显示当前生效值），档位改用可换行布局，行列对齐不再错位。

2. **成就墙重排版**
   - 旧墙是 2 列 × 3 行 + 8 页翻页，48 枚徽章一页只露 6 枚，且绝大多数是灰的，看起来空荡荡。
   - 现在去掉翻页，改成一整面可滚动的自适应网格（手机 3 列，平板自动加列），一屏铺开 6~9 枚。
   - 顶部新增战绩卡：已解锁 X / 48、完成度百分比与进度条——这是整面墙上唯一「在往前走」的东西。
   - 每枚徽章下方露出名字；未解锁的进度型徽章再显示「3 / 10」这样的进度，灰墙上有进度才不像死寂。
   - 排序按你给的规则：已解锁的在前、未解锁的在后；两组内部都按难度升序（越难的越靠后），同难度按固定顺序兜底。

### 安装

## v0.0.85

v0.0.85 - HTML 清洗防漏网、资料库解析加固、横滑手势工程化、文案全量外移

### 更新内容

**一轮代码审查修复（安全加固 + 体验打磨），UI 无大变化：**

1. **HTML 渲染安全加固**：```html 围栏里未闭合/自闭合的危险标签（`<iframe src=…>`、`<script src=…>`、`<object>`、`<form>`、`<button>` 等）此前会原样穿过清洗层，现已全部剥掉——「宁可少显示，不可执行」。

2. **HTML 高度收尾**：生成结束后 HTML 排版块允许收缩，宽度变化重排时不再留一大截空白；流式输出中保持只增不减，气泡不抖。

3. **资料库解析加固**：.docx 解析禁用 DOCTYPE 与实体展开（防别人发来的文件搞 XXE/实体炸弹，被拒文件安全回落为「无法提取」）；超大文档提取上限 64MB→16MB，手机内存更友好。

4. **横滑手势判定工程化**：翻页/展开删除/纵向滚动的分流判定抽成纯函数并补齐边界单测；补上「让道后翻不动页的死手势」兜底（滑到页边界时不再卡住）。三个既有手感不变。

5. **全量文案外移**：255 处界面文案迁入统一资源表（番茄钟/背单词/设置/对话/海报/打印/通知渠道），为后续多语言铺路；成就墙、通知渠道名等一并规范化。

6. **HTML 组件生命周期**：后台延时测量随页面销毁自动取消，不再多持有 WebView 最多 2 秒。

## v0.0.83

v0.0.83 - 思考折叠时机修复、回退涂鸦缩放、LaTeX 黑名单兜底、HTML 围栏公式、OCR 超时放宽

### 更新内容

**本次修复对话生成体验与公式渲染两大块（含 v0.0.82 反馈）：**

1. **思考过程折叠时机修复**：生成回答时，思考块在**答案开始输出的那一刻自动收起**。此前思考块在作答阶段一直展开、把正文顶出屏幕，直到整条消息结束才猛地收起——这就是「会跳转但不折叠」的根因。

2. **回退涂鸦页双指缩放**：裁切/涂鸦页恢复单指手势（一根手指涂鸦或拖框），移除双指缩放/平移。实测手势分流复杂、误触多，整体回退；预览弹窗的放大查看不受影响。

3. **LaTeX 渲染黑名单（渲染端兜底）**：所有公式进渲染器前自动降级——cases/矩阵/行列式环境、\left\right 定界符、\big 系列等已知渲染失败的结构会被自动替换为可渲染写法，公式不再整条显示为红色源码。

4. **HTML 围栏里的公式也能渲染**：```html 排版块中的 $...$ / $$...$$ 行内与独立公式，现在用 KaTeX 原地渲染。

5. **OCR 识别超时放宽（40 秒 → 180 秒）**：视觉模型转写整页手写内容常需 20–90 秒，40 秒熔断会让「测试连接成功」的端点在实际识别时必然超时。测试连接只验证连通性，与推理时长无关。

### 错题本 v0.0.80 更新说明

本次更新重点修复了 HTML 渲染截断、模型思考折叠抖动、主题色显示挤压、番茄钟滑动等问题，并将“MinerU 配置”全量更名为“OCR 配置”；同时深度优化对话多模态相机体验，支持拍照裁剪直接直通大模型对话。

#### 核心更新内容

1. **HTML 渲染重构与自适应防截断**
   - 修复 WebView 视口中 CSS 像素被误当物理像素除以 `density` 导致的严重底部截断问题（高度不再被砍掉 2/3）。
   - 注入 `ResizeObserver` 配合 `HtmlBridge` 实现 DOM 尺寸变化的即时双向高度回传，底部补足安全间距。
   - 统一外链点击拦截，通过系统浏览器安全打开。

2. **模型思考折叠与视口重锚定**
   - 移除与 `reverseLayout` 冲突的 `animateContentSize`，消除收起时的多帧跳变抖动。

3. **设置页主题色双排优雅布局**
   - 将单行 8 色横排重构为 2 行各 4 色网格排布，色块放大至 34dp 且间距充裕，彻底解决窄屏机型最后一个色块被挤压成椭圆的问题。

4. **OCR 配置全量规范化更名**
   - “MinerU 配置”全面更名为“OCR 配置”，“MinerU API Key”更名为“OCR API Key”。
   - 同步更新设置面板所有文案与 README 架构文档，明确支持 MinerU / DeepSeek OCR 等多种引擎。

5. **番茄钟左右滑动手势切换**
   - 引入 Compose `HorizontalPager` 重构番茄钟主页，支持流畅的左右滑动手势切换“番茄时钟”与“统计”，并与顶部选项卡双向无缝联动。

6. **对话拍照裁剪直传大模型**
   - 对话中进入相机拍照、裁剪完成后，图片直接作为多模态图片进入对话输入流，**绝不再误触发错题 OCR 识别管线**。
   - 修复裁剪完成后自动回退（pop）到对话页面的导航行为。

7. **“连拍完成”按钮重新排版与交互**
   - 按钮移至底部操作栏快门右侧，不再遮挡上方相机取景画面。
   - 状态联动：未拍照时显示灰色禁用状态；拍完后高亮纯白并显示已拍张数徽标。
   - 彻底移除容易误触且多余的“不裁切下一张”入口。

8. **相机 UI 极简磨砂质感设计**
   - 去除突兀的主题高光色，采用现代半透明黑玻磨砂底与纯白极简控件。

### 这个版本修了什么

#### 流式输出不再「未触底也自动往下滚」（本次重点）

之前 AI 回答往外冒字时，只要你手动往上滑看过历史，列表还是会被一点点拽回底部；甚至你明明停在中间，内容也会自己往上漂。根因是反向布局把滚动位置钉在「最新一条」上，它每长高一点，你正在读的段落就被推走一截。

现在改成**滚动锚定**：以视口最顶部那条消息为锚点，内容长高时同步补偿滚动量，你眼前的文字纹丝不动；只有你本来就贴在底部时才自动跟随。手指一碰屏幕立刻交出滚动权，向下甩滑停在半路也不会被反向推回去。

## v0.0.14

v0.0.14 - 对话里的不识图模型自动走 MinerU OCR

### v0.0.14 —— 对话里的「不识图模型」自动走 MinerU OCR

用户接的大模型不一定支持多模态（DeepSeek-chat、Qwen-plus 都看不见图）。
本 App 已经接了 MinerU，于是补上一条通路：**先让 MinerU 把图读一遍，再把文字喂给模型。**

#### 新增

- **设置页新增「该模型支持图片」开关**（逐模型配置，默认开 → 存量配置行为不变）
- 关闭后，**对话里发的图片会自动先经 MinerU OCR**，识别出的文字以
  `【图片中的文字内容（由 MinerU 自动识别）】` 为头注入消息正文
- 聊天页输入栏上方显示 **OCR 进度条**（第几张图、当前阶段），全程后台协程执行，不卡界面
- 未配置 MinerU Key 时会明确提示，而不是让模型对着「用户发了张图」瞎猜
- OCR 结果按「路径+修改时间+大小」做磁盘缓存（MinerU 按页计费，不重复烧额度）
- 覆盖**历史轮次**的图片：隔几轮问「刚才那张图」也能用上

#### 技术要点

- `LlmProfile.supportsVision` 默认 `true` 且带默认值，**存量配置反序列化不会丢 Key/URL/模型名**
- 不识图时**不发 `image_url`**（发了只会得到空回答或服务端报错），改为只发文字
- `MineruClient` 抽出可复用入口 `recognizeInto`，目录参数化，`imageDir = null` 时不抽图片
- OCR 取消能正确传播：点「停止」后 MinerU 不会在后台继续烧额度
- `ChatOcrText` 为纯函数（剥图片引用 / 删本机绝对路径 / 截断），可 JVM 单测

#### 校验

- versionCode 14 / versionName 0.0.14
- 签名 SHA256 `e3ba30aec5707e62716bb771c85c461b4aae5cf6c022d8b920125ae33014da54`（与 v0.0.13 同一把钥匙，可直接覆盖安装）
- 无 `debuggable`，DEX 内无任何 `sk-` 密钥
- 单元测试全绿（新增 `ChatOcrTextTest`、`LlmProfileCompatTest`）
