## 1. 一句话

**给埋头苦读的人做的离线优先学习工具箱**：拍下错题它自己认，单词跟着计划背，专注计时还有数据——一个 App 管学习。

- 目标用户：备考的学生（考研/高考/语言考试），每天高频使用
- 核心取舍：**单机优先、隐私优先**——不注册账号、数据只在手机里、API Key 加密存储；联网能力（识别/AI 讲解）全部由用户自己配 Key、自己付配额
- 交互语言：全中文，界面克制、圆角、暗色友好

## 2. 功能全景（七个模块）

### 2.1 错题本（核心）
- **录入三路**：拍题（系统相机 → 裁切 → 识别）、相册批量选图、PDF 导入（文本型直接抽字，扫描型自动转页图走 OCR）；外加零依赖的**手动录入**（没配任何 Key 也能用）
- **识别流水线**：零依赖 PDF 文本抽取（对象流 PDF 兜底 OCR）→ MinerU 文档解析或视觉模型直连 → 大模型整理成结构化题目（题干/选项/答案/解析/知识点/难度），支持多题一张图
- **整理与复习**：学科/掌握度筛选、置顶、搜索、左滑归档；复习队列按掌握度调度
- **打印重做**：勾选题目排版成 A4（字号/字体/答案显隐/留白重做），WebView 导出
- 设计原则：识别失败永远给「手动录入」退路；识别任务是队列制（可取消、可重试、断点续跑）

### 2.2 AI 对话
- 多渠道多 Key：一个地址下挂多把 Key 自动换切（鉴权失败/额度耗尽自动换下一把）；对话内可随时切模型
- 附件：图片（视觉模型或 OCR 中转）、PDF、资料库文件（@ 引用）
- 工具：联网搜索（Tavily/DeepSeek）、生图、**ask_user**（向用户提问的选项卡片）、save_memory
- **临时对话**：退出即归档不丢内容；历史抽屉左滑置顶/重命名/归档（无缝圆角拼贴，互斥展开）
- 流式输出 + 思考块折叠 + 公式逐条渲染（KaTeX）

### 2.3 记忆
- 用户一句话 → 模型改写成**分节记忆文档**（个人背景/学习情况/偏好）；每轮对话自动注入
- 模型也可在对话里主动 save_memory；输入命中记忆意图词时后台自动提取（双闸避免每轮多花调用）

### 2.4 资料库（v0.0.113+）
- 收文件（md/txt/json/csv/docx/pdf/xlsx），原文落库，对话可引用
- **向量检索**：切块 → OpenAI 兼容 embeddings → 本地余弦 + 关键词 RRF 融合排序；检查点式增量索引（hash 没变的块不重嵌）
- **扫描 PDF 兜底**（v0.0.131）：抽不出文本的 PDF 自动渲染页图走当前识别渠道逐页转写（上限 50 页）
- 语义检索与关键词检索融合：嵌入未配置自动降级为纯关键词

### 2.5 背单词
- 四种考法（认词/选义/拼写/辨析）随机出题；答错进复习队列（记忆曲线）
- 每日新词上限（1..500 档位+自定义）、打卡热力图、词库进度

### 2.6 番茄钟
- 按学科任务的专注计时 + 白噪音；今日/近 7 天/近 30 天统计
- **任务归档**（v0.0.126）：归档的任务可恢复，历史记录保留；补记弹窗时间可清空重填

### 2.7 成就墙
- **100 枚徽章 / 11 类**（刷题、专注、背单词、对话、资料库、元成就……），纯函数判定引擎；已解锁在前、组内难度升序

## 3. 设置与网络（用户长期挂 VPN 的场景）

- 设置四组折叠：**AI 与识别**（识别方式/OCR 渠道/大模型/识图模型/生图渠道/联网搜索/记忆）、**学习**（学习工具/背单词/番茄钟/复习提醒/打印默认）、**数据**（备份/归档内容/单词书数据/番茄钟数据）、**通用**（主题/用量/网络/关于）
- **OCR 双渠道**：MinerU（文档级解析，出 Markdown+配图）或任意 OpenAI 兼容视觉模型（识图转写）；多渠道可存可切
- **网络出口模式**：AUTO（国内供应商直连名单强制直连——MinerU/商汤/国内大厂，其余走系统代理）/ 全部直连 / 跟随系统。**这是为「长期挂 VPN」的用户设计的**：国内服务被塞进代理出口会又慢又容易被拒
- Key 全部 EncryptedSharedPreferences；明文偏好（搜索/embedding/直连名单等）在 DataStore

## 4. 数据与保留策略

- 错题/会话/任务：软删 → 回收站 30 天 → 物理清理（级联清附件）
- 会话归档 7 天自动、归档满 3 个月**且 3 个月没动过**才销毁；归档会话来信自动解归档
- 会话表禁止整行 UPDATE（并发丢更新教训，见 HANDOFF §4）

## 5. 设计原则（写代码前先读）

1. **没有 Key 也要能用**：每个联网功能都有本地退路（手动录入、关键词检索、本地统计）
2. **失败可恢复**：识别是队列、索引有检查点、删除有回收站、临时对话进归档
3. **不误导用户**：错误文案必须说清楚是哪条路失败、为什么（配额/网络/Key 分开说）
4. **一处交互一处实现**：左滑、裁切、公式渲染都是共享组件，页面不许各抄一份
5. **国内优先**：国内供应商直连；国外服务（OpenRouter 等）才需要用户自己的网络出口
